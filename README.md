## 🔮 The Prophecy (About)

Ever caught yourself having one of these shower thoughts?

> *"Wait... was Mundungus Fletcher actually useful or just a kleptomaniac?"*  
> *"How many named Weasleys can I list before my brain shorts out?"*  
> *"Who was that one wizard who blew up a feather in Charms class again?"*

This project was forged over caffeine and sheer curiosity to answer those exact questions. It queries the **PotterDB API** on the fly so you can pull up character details faster than Hermione’s hand goes up in Potions class.

Designed for Potterheads, curious Muggles, and developers looking for an excuse to play with React 19, Tailwind 4, and smooth Motion animations.

## 🚀 Quick Summoning (Getting Started)

No wands required—just Node.js and a functional terminal.

**1. Clone the repository**
```bash
git clone https://github.com/your-username/potterlens.git
cd potterlens
```

**2. Brew the dependencies**
```bash
npm install
```

**3. Cast the dev server spell**
```bash
npm run dev
```

Point your broomstick to `http://localhost:5173` and start exploring.
